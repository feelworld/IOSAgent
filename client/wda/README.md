# WDA IPA

Place your `WebDriverAgent.ipa` file in this directory.

The client agent will automatically install it onto new USB-connected jailbroken devices.

## Requirements
- Device must be **jailbroken**
- Device should have **AppSync Unified** installed (via Cydia/Sileo)
- The IPA must be a properly signed/packaged WebDriverAgent

## How to get the IPA
1. Build from source: https://github.com/appium/WebDriverAgent
2. Or use a pre-built version for your iOS version
